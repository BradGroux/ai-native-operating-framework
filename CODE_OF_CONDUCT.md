# Code of Conduct

## Purpose

Participation in the AI-Native Operating Framework community should make the
framework clearer, safer, more useful, and easier to trust.

## Expected Conduct

Participants must:

- discuss ideas and evidence without attacking people;
- represent experience, sources, authority, and uncertainty honestly;
- respect privacy, confidentiality, intellectual property, and professional
  boundaries;
- make room for correction, dissent, and questions;
- keep criticism specific, relevant, and proportionate; and
- follow maintainer instructions used to contain harm or restore a productive
  discussion.

## Unacceptable Conduct

Harassment, threats, discrimination, sexualized conduct, deliberate
misrepresentation, doxing, publication of private or confidential material,
retaliation, sustained disruption, and knowingly unsafe guidance are not
acceptable.

## Scope

This code applies to repository issues, pull requests, reviews, discussions,
release activity, and other spaces where someone represents the framework or
its community.

## Reporting and Enforcement

Report a concern privately to the founding steward through a private contact
route listed on the [`@BradGroux`](https://github.com/BradGroux) GitHub profile.
If no suitable private route is available, select the
`Private conduct contact request` issue form and submit it without sensitive
details. The steward will establish a private channel.

The steward may correct or remove content, limit participation, close a
discussion, or block a participant when necessary. Decisions should state the
reason and remain proportionate to the conduct and risk. If the steward is
materially involved, an uninvolved reviewer should participate when practical,
and any governance limitation must be recorded.
